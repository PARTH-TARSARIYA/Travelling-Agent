# AI Travel Agent

This project is an AI-powered travel assistant that helps users plan trips more easily. The agent can suggest destinations, generate travel itineraries, and assist users with travel-related information through an interactive interface.

I built this project to explore Agentic AI workflows and understand how AI agents can automate real-world tasks like travel planning and recommendations.

## Features

* AI-based travel recommendations
* Personalized itinerary generation
* Destination suggestions
* Interactive chat-based assistance
* Modular agent workflow
* Easy-to-use interface

## Tech Stack

* Python
* LangChain / LangGraph
* Groq API
* Streamlit / Flask
* LLMs

## How It Works

The user provides travel-related inputs such as destination preferences, budget, or trip duration. The AI agent processes the request, plans the workflow, and generates suitable travel suggestions and itineraries.

## Installation

```bash
git clone https://github.com/PARTH-TARSARIYA/Travelling-Agent
cd <project-folder>
pip install -r requirements.txt
```

## Run the Project

```bash
python app.py
```
